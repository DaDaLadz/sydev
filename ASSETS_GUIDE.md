# Assets Guide - Image Files Needed

This guide explains which image files you need to add to complete the landing page redesign.

## Directory Structure Created

```
/public/
├── icons/           # Service icons
└── logos/           # Logo variations
```

## Required Logo Files

Place these in `/public/logos/`:

1. **logo-color.png** - Full color logo (green cart + black text)
   - Used in: Hero section
   - Recommended size: 400px wide (maintains aspect ratio)

2. **logo-icon-green.png** - Icon only (green cart)
   - Used in: Navigation header
   - Recommended size: 64px × 64px

3. **logo-black.png** - All black logo (or use logo-color.png)
   - Used in: Footer
   - Recommended size: 300px wide

## Required Service Icon Files

Place these in `/public/icons/`:

1. **icon-storefront.png** - Storefront + Infrastructure icon (with green blob background)
   - Service: Store Design & Setup
   - Recommended size: 256px × 256px

2. **icon-cart-tools.png** - Cart + Tools icon
   - Service: Development & Technical
   - Recommended size: 256px × 256px

3. **icon-analytics.png** - Analytics + Growth icon (magnifying glass + chart)
   - Service: Optimization & Growth
   - Recommended size: 256px × 256px

4. **icon-pencil.png** - Pencil icon
   - Service: Strategic Consulting
   - Recommended size: 256px × 256px

## How to Add Files

1. Save your image files with the exact names listed above
2. Place them in the correct directories as specified
3. The site will automatically use them - no code changes needed!
4. If an image is missing, the site will show a fallback (text or placeholder)

## Icon Mapping Reference

From your uploads, these correspond to:
- Icon #3 (Storefront with green blob) → icon-storefront.png
- Icon #5 (Cart + Tools black) → icon-cart-tools.png
- Icon #6 (Analytics magnifying glass) → icon-analytics.png
- Icon #8 (Pencil) → icon-pencil.png

## Testing

After adding the files:
1. Refresh the browser to see your images
2. Check all sections: Hero, Navigation, Services, Footer
3. Verify responsive behavior on mobile devices

## Notes

- All images should be PNG format for best quality
- Transparent backgrounds work best for logos and icons
- The site is optimized for the grungy, industrial aesthetic you provided
- Icons will be displayed at 128px × 128px on desktop, 96px × 96px on mobile
